# Database Schema Documentation

## Tables

### 1. registrations
```sql
create table public.registrations (
  registration_id text not null,
  first_name text null,
  other_names text null,
  username text null,
  email text null,
  sex text null,
  "city / town / district" text null,
  country text null,
  club text null,
  pin_hash text null,
  created_at timestamp with time zone null default now(),
  dob date null,
  country_code text null,
  email_verified boolean null default false,
  subscription integer not null default 1,
  constraint Registration Sample_pkey primary key (registration_id),
  constraint registration_sample_country_code_fkey foreign KEY (country_code) references countries (iso_alpha2)
) TABLESPACE pg_default;
```

### 11. health_goal
```sql
create table public.health_goal (
  health_id serial not null,
  registration_id text not null,
  record_date date not null,
  heart_rate_bpm integer null,
  steps integer null,
  sleep_hours numeric(4, 2) null,
  blood_oxygen_spo2 numeric(4, 1) null,
  overall_health_score numeric GENERATED ALWAYS as (
    (
      (
        (
          ((COALESCE(heart_rate_bpm, 0))::numeric * 0.25) + ((COALESCE(steps, 0))::numeric * 0.0005)
        ) + (
          COALESCE(sleep_hours, (0)::numeric) * (10)::numeric
        )
      ) + (COALESCE(blood_oxygen_spo2, (0)::numeric) * 0.5)
    )
  ) STORED (6, 2) null,
  constraint health_goal_pkey primary key (health_id),
  constraint fk_registration foreign KEY (registration_id) references registrations (registration_id)
) TABLESPACE pg_default;
```

## Notes

- All activity column names are lowercase with underscores (e.g., `activity_id`, `registration_id`, `activity_date`)
- Events use lowercase column names: `event_id`, `event_name`, `starts_at`, `ends_at`
- The `event_enrollments` table has mixed casing: `enrollment_id` and `registration_id` are lowercase, but `"EventID"`, `"First_Name"`, `"Other_Names"`, `"Email"`, `"Status"`, `"Enrolled_At"` are quoted/mixed case
- Medal criteria fields on events: `medal_min_daily_distance`, `medal_min_cumulative_distance`, `medal_date_start`, `medal_date_end`
- External activity submissions no longer have status/review columns - submissions are deleted after approval or rejection
- FriendID is hidden from users (system-generated)
- All pace values are stored as km/h but displayed as min/km in the UI
- Dates are displayed as dd mmm yyyy format (e.g., "15 Dec 2024")
